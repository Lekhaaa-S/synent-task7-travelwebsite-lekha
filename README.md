# Yatra Travels

A simple multi-page travel website built with HTML, CSS, and JavaScript.

## Pages
- `index.html` — Home page with hero section and destination highlights
- `about.html` — About page
- `services.html` — Services page
- `contact.html` — Contact page

## Features
- Responsive layout
- Sticky navigation with scroll effect
- Smooth scroll on the home page
- Clean shared styling in `style.css`
